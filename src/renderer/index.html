Cadangkan & Pulihkan Data

Untuk pindah ke komputer lain: Cadangkan di sini → salin file .db (flashdisk/email) → Pulihkan di komputer baru.

Catatan

  • Untuk Gmail: aktifkan Verifikasi 2 Langkah, lalu buat App Password dan gunakan sebagai Password SMTP.
  • Password SMTP disimpan terenkripsi dengan akun Windows.
  • Saat tutup shift, data penjualan shift hanya dihapus setelah server SMTP membalas 250 OK. Salinan file laporan tetap tersimpan di folder laporan.
  • Database dicadangkan otomatis setiap hari (14 salinan terakhir).

Pengguna & Hak Akses

Admin: semua menu. Gudang: Mutasi, Penerimaan, Daftar Barang, Cetak Barcode. Kasir: Kasir / Pembayaran, Laporan Shift, dan Daftar Barang (hanya lihat). Akun disimpan di database PC Gudang dan berlaku di semua komputer.

Mode Komputer & Jaringan

Untuk 2 komputer: PC Gudang menjadi Server (menyimpan database), PC Kasir memakai mode Kasir dan terhubung ke PC Gudang lewat jaringan toko. Stok selalu sama di kedua komputer.

Ketik alamat IP & kode ini di Pengaturan PC kasir. Saat pertama kali, Windows Firewall akan bertanya — pilih Allow / Izinkan untuk jaringan Private.
